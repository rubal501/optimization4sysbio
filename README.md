# Opt4sysbio

A compilation  of optimization methods for systems biology written in Julia. 

## Implemented methods
- EACOP (Egea, Martí & Banga, 2010), **compatible with SciML**.

## References:
- Egea, J. A., Martí, R., & Banga, J. R. (2010). An evolutionary method for complex-process optimization. Computers & Operations Research, 37(2), 315-324.
